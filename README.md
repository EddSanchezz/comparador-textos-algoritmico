El estudio computacional de textos permite explorar y analizar volúmenes de datos derivados de la
producción científica utilizando métodos cuantitativos y cualitativos. Se fundamenta en las
matemáticas y la estadística, para establecer descripciones, relaciones, inferencias y presentaciones
de la información suministrada por publicaciones científicas. En este contexto, la extracción de
patrones, el análisis de similitud textual, la búsqueda, entre otros, resultan fundamentales. Para este
proyecto, el dominio de conocimiento girará en torno a la inteligencia artificial generativa. Se busca
que el estudiante enfrente el reto algorítmico de procesar lenguaje natural no estructurado,
comprendiendo la transición matemática y lógica desde las estructuras de datos y algoritmos
clásicos, hasta los modelos modernos implementados con Inteligencia Artificial (IA).
